# Green API Chat

## 1. Системные требования
Перед началом установки убедитесь, что на вашем компьютере установлены следующие компоненты:
* **Node.js** (рекомендуется версия 22.x или выше). Проверить версию: `node -v`
* **npm** (поставляется вместе с Node.js). Проверить версию: `npm -v`

## 2. Установка зависимостей
Выполните команду в корневой папке проекта:
```bash
npm install
```

## 3. Запуск приложения в режиме разработки
Для запуска локального сервера разработки выполните команду:
```bash
npm run dev
```

**Ожидаемый результат:**
В терминале появится информация об успешном запуске сервера Vite. 
Приложение будет доступно в браузере по адресу: http://localhost:[номер порта] (или по другому порту, если этот занят, о чем Vite сообщит в терминале).

## 4. Сборка для Production
Чтобы протестировать, как приложение будет работать после оптимизации и сборки:

**1. Выполните сборку:**
```bash
npm run build
```
*Данная команда запустит проверку типов TypeScript (`tsc`) и соберет оптимизированный бандл проекта в директорию `dist`.*

**2. Запустите локальный сервер предварительного просмотра:**
```bash
npm run preview
```
Сервер запустит собранную (production) версию приложения по локальному адресу (обычно `http://localhost:[номер порта]`).
